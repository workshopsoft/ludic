# smoke.txt - a scripted session for ludic ui-preview (protocol-v1.md), to be run by hand or by a
# small driver: `bin/ludic-ui-preview < requests` where the requests are the `> ` lines below, in order.
#
#   > LINE     a request, sent as it stands (without the "> ")
#   < TEXT     some reply line of that request contains TEXT (in order within the reply)
#   <= LINE    the request's terminal line is exactly LINE
#   <! TEXT    no reply line of that request contains TEXT
#
# No font is loaded, so a character measures half the font size, and the viewport is 1920 x 1080, so
# a design pixel is a screen pixel and the default text is 16 px (a 4-letter word is 32 wide).
