sig: scene Name lasts N then Next { }
tip: A timed scene: after N seconds it moves on.
order: 52
---

<code>lasts N then Next</code> makes a scene timed - a banner, a splash - that moves to <code>Next</code> by itself once <code>N</code> seconds have passed.
