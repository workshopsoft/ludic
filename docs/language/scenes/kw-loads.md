name: loads
category: scenes

tokens: loads
sig: scene Name loads then Next { }
tip: A loading scene: pumps the asset queue with a bar, then moves on.
order: 54
---

<code>loads then Next</code> makes a scene the loading screen: the engine pumps the asset queue, draws a progress bar and enters <code>Next</code> when everything queued is ready.
